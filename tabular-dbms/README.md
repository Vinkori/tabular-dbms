# Таблична СУБД

Навчальна клієнт-серверна система для створення табличних баз даних,
керування таблицями й рядками та вилучення повторюваних записів.
Вебінтерфейс і десктопний застосунок працюють через спільний REST API.
Дані зберігаються на сервері у JSON-файлах.

**Варіант:** додаткові типи `color` та `colorInvl`; додаткова операція —
вилучення повторюваних рядків.

## Можливості

- Створення, відкриття та перегляд списку баз даних.
- Створення таблиць із перевіркою назви, схеми та типів колонок.
- Видалення таблиць.
- Додавання, перегляд і часткове редагування рядків.
- Типи `integer`, `real`, `char`, `string`, `color`, `colorInvl`.
- Вилучення повторюваних рядків зі збереженням першого входження та порядку.
- Автоматичне збереження успішних змін у серверному сховищі.
- Імпорт та експорт баз у JSON.
- Вебклієнт українською та десктопний клієнт із відповідними діями.
- Документація API й автоматизовані тести.

Модель не встановлює власного фіксованого ліміту кількості таблиць, колонок
або рядків. Практичні обмеження визначаються пам’яттю, розміром файлів і
часом обробки. Зв’язки між таблицями не реалізуються за умовою завдання.

## Запуск у Windows / PyCharm

Рекомендовано Python 3.12. Пакет перевірено на Python 3.12.14 у Linux;
окремий запуск у Windows у межах цієї перевірки не виконувався.

Розпакуйте проєкт, відкрийте папку `tabular-dbms` у PyCharm.
Виконуйте команди з папки, де лежить `requirements.txt`.
Команди PowerShell нижче не потребують активації віртуального середовища.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Якщо Python 3.12 уже вибраний у PyCharm, замість першої команди можна
використати `python -m venv .venv`.

У першому терміналі запустіть сервер:

```powershell
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Поки він працює, відкрийте:

- [Вебінтерфейс](http://127.0.0.1:8000/).
- [Swagger UI — документацію API](http://127.0.0.1:8000/docs).
- [Перевірку сервера](http://127.0.0.1:8000/api/health): очікується `{"status":"ok"}`.

У другому терміналі з тієї самої папки запустіть desktop:

```powershell
.\.venv\Scripts\python.exe -m desktop.main
```

Обидва клієнти використовують один сервер. Щоб побачити зміни іншого
клієнта, натисніть «Оновити». Зупинка сервера — `Ctrl+C`.
У PyCharm виберіть інтерпретатор `.venv/Scripts/python.exe`.
API-ключі та `.env` для проєкту не потрібні.

### Linux / macOS

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

В іншому терміналі: `.venv/bin/python -m desktop.main`.
Для desktop потрібні графічне середовище та системні бібліотеки Qt.

## Демонстрація

1. Запустіть сервер і відкрийте вебінтерфейс.
2. Імпортуйте `examples/demo_database.json`.
3. Відкрийте таблицю `Samples`: у ній 3 рядки та всі 6 типів даних.
4. Вилучіть повтори: має залишитися 2 рядки, вилучено 1.
5. Змініть рядок та експортуйте базу в JSON.
6. Відкрийте desktop, виберіть ту саму базу й таблицю та оновіть дані.
7. Перезапустіть сервер: база має залишитися у списку.

Приклад містить синтетичні дані. Повторний імпорт створює нову базу
з новим UUID. Робочі JSON-файли сервера до репозиторію не входять.

## Типи й правила перевірки

| Тип | Правило | Приклад JSON |
|---|---|---|
| `integer` | Ціле число або його текстовий запис; bool не приймається | `42` або `"42"` |
| `real` | Скінченне число; NaN та нескінченність заборонені | `3.14` або `"3.14"` |
| `char` | Рівно один Unicode-символ за len у Python | `"A"` |
| `string` | Текст, у тому числі порожній | `"Sample"` |
| `color` | Цілі RGB-канали 0..255 | `{"red":10,"green":20,"blue":30}` |
| `colorInvl` | Початкова й кінцева RGB-межі; start ≤ end поканально | `{"start":{"red":0,"green":0,"blue":0},"end":{"red":255,"green":255,"blue":255}}` |

Назви не можуть бути порожніми. Назви колонок у таблиці та назви таблиць
усередині бази мають бути унікальними. Додавання рядка потребує всіх полів
схеми без зайвих; редагування може передавати лише змінені поля.
Некоректна зміна не повинна частково змінювати дані.

Рядки повторні, якщо збігаються нормалізовані значення **всіх** колонок.
UUID не бере участі в порівнянні. Перетин колірних інтервалів не означає
їхньої рівності. Множина канонічних ключів дозволяє зберігати перші
входження, їхні UUID та початковий порядок.

## REST API

Префікс — `/api`; запити й відповіді — JSON. UUID повертаються під час
створення відповідних об’єктів.

| Метод | Шлях без префікса /api | Дія |
|---|---|---|
| GET | `/health` | Стан сервера |
| GET | `/databases` | Список баз |
| POST | `/databases` | Створити базу |
| GET | `/databases/{db_id}` | Відкрити базу |
| POST | `/databases/import` | Імпортувати базу |
| GET | `/databases/{db_id}/export` | Експортувати базу |
| POST | `/databases/{db_id}/tables` | Створити таблицю |
| GET | `/databases/{db_id}/tables/{table_id}` | Схема й рядки таблиці |
| DELETE | `/databases/{db_id}/tables/{table_id}` | Видалити таблицю |
| POST | `/databases/{db_id}/tables/{table_id}/rows` | Додати рядок |
| PATCH | `/databases/{db_id}/tables/{table_id}/rows/{row_id}` | Змінити поля рядка |
| POST | `/databases/{db_id}/tables/{table_id}/remove-duplicates` | Вилучити повтори |

Приклад створення таблиці:

```json
{
  "name": "Samples",
  "columns": [
    {"name": "number", "type": "integer"},
    {"name": "label", "type": "string"}
  ]
}
```

Додавання рядка: `{"values":{"number":42,"label":"Sample"}}`.
Редагування: `{"updates":{"label":"Updated"}}`.

Спільна форма помилки:

```json
{"error":{"code":"VALIDATION_ERROR","message":"Опис помилки","field":"number"}}
```

Статуси: `201` — створено, `204` — видалено, `404` — не знайдено,
`409` — конфлікт, `422` — некоректні дані, `500` — помилка сервера/сховища.
Докладні моделі запитів і відповідей наведені у Swagger UI.

## Тестування

Windows:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Linux без екрана:

```bash
QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q
```

Сервер і домен без тестів Qt:

```powershell
.\.venv\Scripts\python.exe -m pytest -q --ignore=tests/test_desktop.py
```

Тести охоплюють типи, схеми, рядки, дублікати, збереження, сервіси, API,
помилки, видачу вебресурсів і desktop-взаємодію. Вебтести перевіряють
HTTP-видачу ресурсів, а не повний браузерний сценарій. Desktop-тести
використовують Qt offscreen і внутрішній HTTP-транспорт.

Перевірка підготовленого пакета: **313 passed, 1 warning** на Python 3.12.14
у Linux (Qt offscreen). Попередження Starlette стосується майбутньої
зміни HTTP-клієнта TestClient; помилок тестів немає.

Додатково перевірено окремий процес Uvicorn через справжні HTTP-запити:
імпорт усіх шести типів, вилучення повторів, редагування, відхилення
некоректного RGB, експорт та збереження даних після перезапуску сервера.

`requirements.txt` містить прямі залежності, `requirements-lock.txt` —
знімок версій пакетів перевіреного середовища. Для встановлення цих версій
використовуйте `pip install -r requirements-lock.txt`. Це не гарантує
сумісності з усіма ОС і версіями Python.

## Межі реалізації

Це часткова навчальна СУБД: SQL, зовнішні ключі та зв’язки між таблицями
не реалізовані. Немає окремого видалення рядка, перейменування баз/таблиць,
зміни чи перестановки колонок готової таблиці.

Сховище читає й перезаписує файл бази цілком. Спільний Lock узгоджує
операції одного процесу; міжпроцесне блокування відсутнє. Запускайте один
процес Uvicorn без кількох workers для спільного сховища.
Автентифікація, ролі й аудит не реалізовані. Стандартний запуск призначений
для локальної навчальної демонстрації на `127.0.0.1`.
